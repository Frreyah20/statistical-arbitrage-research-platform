# Statistical Arbitrage Research Platform

A quantitative research platform for discovering and evaluating cointegrated equity pairs using statistical arbitrage techniques.

## Features

- Correlation analysis
- Cointegration testing
- Hedge ratio estimation
- Spread construction
- Rolling Z-score signal generation
- Mean reversion backtesting
- Sharpe ratio and drawdown analysis
- Pair ranking engine
- Walk-forward testing
- Machine learning based pair evaluation
- Automated reporting and visualizations

## Tech Stack

- Python
- Pandas
- NumPy
- Statsmodels
- Scikit-Learn
- Matplotlib
- yfinance

## Project Structure

src/ → research engine

results/ → generated outputs

results/plots/ → visualizations

## Run

```bash
python src/main.py
```
